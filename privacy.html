Privacy Policy

Effective Date: August 17, 2026

Overview

Ned is a completely offline, client-side browser extension designed for privacy and speed.

Data Collection

This extension collects zero personal data, telemetry, or analytics. It does not call external APIs. All CVSS calculations run locally in your browser through embedded JavaScript libraries.

Permissions

The extension uses minimal permissions, including local storage and clipboard copy support when you choose to copy a vector string or CWE ID. It does not track browsing history or read web page content.

Open Source

You can verify this in the open-source repository on GitHub.
